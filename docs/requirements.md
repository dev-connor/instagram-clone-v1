## 2. 기능 요구사항

### 2.1 User (회원/인증/프로필)
- FR-U1: 사용자 이름(username, unique) / 이메일(unique) / 비밀번호로 회원가입
- FR-U2: username 또는 email + 비밀번호로 로그인, 인증 토큰 발급
- FR-U3: 로그인한 사용자의 정보 조회(닉네임, 실명, 프로필 이미지, 소개글)
- FR-U4: 프로필 정보 수정(실명, 소개글, 프로필 이미지)
- FR-U5: 특정 사용자의 공개 프로필 조회 시 게시물 수 / 팔로워 수 / 팔로잉 수 함께 노출
- FR-U6: username 검색(다른 사용자 찾기) — P2

### 2.2 Post (게시물)
- FR-P1: 이미지 + 캡션으로 게시물 작성
- FR-P2: 홈 피드 조회 — 내가 팔로우한 사용자 + 본인의 게시물을 최신순으로 페이지네이션 조회
- FR-P3: 특정 사용자의 게시물 목록 조회(프로필 그리드용)
- FR-P4: 게시물 단건 상세 조회(좋아요 수, 댓글 수 포함)
- FR-P5: 본인 게시물 삭제
- FR-P6: 본인 게시물 캡션 수정 — P2

### 2.3 Comment (댓글)
- FR-C1: 게시물에 댓글 작성
- FR-C2: 게시물의 댓글 목록 조회(작성시간순, 페이지네이션)
- FR-C3: 본인 댓글 삭제
- FR-C4: 대댓글(댓글에 답글) — P2, 데이터 모델은 1단계에서 자기참조로 대비
- FR-C5: 댓글에 좋아요 — P2 (참고 이미지에 있으나 MVP 범위 밖, Like 대상은 Post로 한정 권장)

### 2.4 Like (좋아요)
- FR-L1: 게시물에 좋아요 등록 (사용자-게시물 조합 unique, 중복 좋아요 방지)
- FR-L2: 좋아요 취소
- FR-L3: 게시물의 좋아요 수 조회
- FR-L4: 특정 게시물에 대한 본인의 좋아요 여부 조회(피드에서 하트 채움 상태 표시용)
- FR-L5: 좋아요 누른 사용자 목록 조회 — P2

### 2.5 Follow (팔로우)
- FR-F1: 다른 사용자 팔로우
- FR-F2: 팔로우 취소(언팔로우)
- FR-F3: 팔로워/팔로잉 수 조회
- FR-F4: 팔로워/팔로잉 목록 조회
- FR-F5: 본인 → 대상 사용자에 대한 팔로우 여부 조회(프로필 버튼 상태용: "팔로우" vs "팔로잉")
- FR-F6: 자기 자신 팔로우 금지, 중복 팔로우 방지(unique 제약)

## 4. 우선순위 요약

- **P0 (필수, be-spec/be-impl 대상)**: User 가입·로그인·프로필 조회, Post CRUD(작성/조회/삭제), Comment 작성·조회·삭제, Like 등록·취소·조회, Follow 등록·취소·조회
- **P1**: 프로필 수정, 팔로워/팔로잉 목록, 게시물 페이지네이션 정교화
- **P2 (차기 이후)**: 대댓글, 댓글 좋아요, 게시물 수정, 사용자 검색, 좋아요 누른 사람 목록
- **Out of scope (본 클론 범위 제외)**: 스토리, DM/메시지, 공유 시트의 외부 공유, 릴스, 알림, 해시태그/검색 탐색 탭

## 5. 비기능 요구사항
- 인증: JWT 기반, 로그인 필요한 API는 Bearer 토큰 필수
- 페이지네이션: 피드/댓글/댓글목록/팔로워목록 등 목록성 API는 cursor 또는 offset 기반 페이지네이션 적용
- 이미지 업로드: MVP는 이미지 URL 문자열 저장(실제 파일 업로드/스토리지 연동은 범위 밖, mock 가능)
- 정렬: 피드·댓글은 최신순(createdAt DESC) 기본
